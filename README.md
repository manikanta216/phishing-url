# PhishShield

PhishShield is an AI-powered phishing URL detector built with Flask, scikit-learn, and MySQL.

## Project Structure

```
PhishShield/
├── app.py
├── config.py
├── requirements.txt
├── templates/

│   ├── register.html
│   ├── login.html
│   ├── dashboard.html
│   ├── history.html
│   └── result.html
├── static/
│   ├── css/style.css
│   ├── js/script.js
│   └── images/
├── database/
│   ├── schema.sql
│   └── database.py
├── models/

│   └── feature_extraction.py
├── utils/
│   ├── predictor.py
│   └── helper.py
└── README.md
```
